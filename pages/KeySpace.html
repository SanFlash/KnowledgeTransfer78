What Key Space Is

Product overview, key vocabulary, and three clients

Key Space is a B2B inventory, warehouse, and order management SaaS for small and mid-sized businesses. Customers use it to track products across multiple warehouses, receive purchase orders, fulfill customer orders (synced from Shopify, Amazon, WooCommerce, etc.), manage lot numbers and expiration dates, and scan barcodes on the warehouse floor via mobile.

Key Vocabulary

TermMeaning
OrganizationA customer's company account. All data is scoped to an org.
UserA person who logs in. One user can belong to multiple organizations.
RoleAdmin, Manager, User, or Viewer — controls what actions a person can take within an org.
Plan TierStarter / Growth / Pro / Enterprise — controls which features the org can access and how many items/warehouses/orders they get.
Inventory ItemA specific SKU in a specific warehouse (quantity, location, etc.).
ProductThe catalog entry (name, description, images, cost). Products have inventory items.
LotA batch of product with an expiration date — used for food, pharma, cosmetics.
Warehouse LocationA named bin, shelf, or aisle within a warehouse (Growth+ only).

How to Think About Testing

Four principles that make you a better tester for this product

🔴 Principle 1 — Tenant Isolation Is the #1 Risk
Every piece of data belongs to an organization. A user in Alpine Logistics must never be able to see, search, or access data from Pacific Traders — even if they know a valid ID from that org. Finding a way to cross that boundary (URL manipulation, API call, etc.) is a Critical bug regardless of how contrived the path is.

How to probe: When viewing something in Org A (e.g., /products/some-uuid), copy that UUID, log in as a user in Org B, and try to access /products/that-uuid. You should get a 404 or 403 — not the data.
⚠️ Principle 2 — Role Permissions Are Enforced Twice
The UI hides or disables things a user cannot do. But the server also rejects those requests. Both must agree. A Viewer should not see a "Delete" button AND if somehow they trigger the delete, the server should refuse it with a 403.

How to probe: Log in as a Viewer. Right-click a disabled button → Inspect Element → try removing the disabled attribute in DevTools and clicking it. The server should block it with a 403. If deletion succeeds → High bug.
🔒 Principle 3 — Plan Gates Are Enforced Twice Too
Same pattern: Starter-plan UI shows a lock/upgrade overlay on Growth features. But calling the Growth feature directly via Postman as a Starter user should return a 403 with the required plan in the response. If it returns data instead → High bug.
ℹ️ Principle 4 — "Works on My Machine" Is the Enemy
Every bug report must include: browser + OS + viewport + account + organization + plan tier + exact steps. A bug you cannot reproduce from your own report is useless.

Communication & Escalation

How and when to communicate with Andre

📅 Daily Status

Post the daily report (Section 9 format) at the end of each working day in the agreed Slack channel or shared document.

🚨 Critical Bugs

Do not wait for the daily report. File the bug and ping Andre immediately in the shared Slack channel or via direct message.

🚧 Blockers

If you cannot proceed with a scenario (missing credentials, feature not deployed, environment down): mark as BLOCKED in the matrix with an explanation, include it in the daily report, and ping Andre the same day. Do not silently skip and mark NT.

❓ Questions About Scope

If a behavior is unclear and you're not sure whether to file a bug, ask — include a screenshot. Never assume "that's probably fine."

🌐 Environment Issues

If staging appears to be down or returning unexpected errors across multiple unrelated scenarios, stop testing and notify Andre immediately rather than filing many unrelated bugs that may all trace to the same root cause.

🏁 Wrapping Up

At the end of the engagement, schedule a 30-minute sign-off call (or async summary) reviewing: all open bugs, all BLOCKED scenarios, any patterns you noticed, and your overall quality assessment of the product.
